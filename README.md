# Patchpit

Patchpit is a malleable software/runtime experiment: an Automerge-backed shell
for small apps, shared state, and runtime boundaries.

Automerge documents are the canonical source of document state. Use Tarstate by
default for React/app derived state, projections, live views, indexes, schemas,
and write intents.

Specs and protocol notes live in [`docs/`](docs/). The seeded Patchpit
filesystem serves that directory as `/docs`.
